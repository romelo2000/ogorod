# 🌱 Огород

Умный помощник для огорода — работает **без интернета** и **без ключей**.

## Возможности

- 🌙 **Лунный календарь** — полностью расчётный, работает для любого года
- 🌡️ **Погода и температура почвы** — Open-Meteo API (без ключей)
- 📅 **Календарь посадок** — что и когда сажать
- 📋 **План на год** — полный календарь работ по месяцам
- 📊 **История погоды** — сохраняется локально в браузере
- 🌱 **18 культур** — картофель, морковь, лук, чеснок, капуста, томаты и др.

## Онлайн

Приложение доступно по адресу: https://romelo2000.github.io/ogorod/

## Установка на телефон (Android)

1. Скачайте `Огород.apk` из раздела Releases
2. Откройте файл на телефоне
3. Разрешите установку из неизвестных источников
4. Установите и пользуйтесь!

## Технологии

- **Frontend**: HTML, CSS, JavaScript (ES modules)
- **Mobile**: Capacitor (Android)
- **Desktop**: Electron (macOS, Windows, Linux)
- **Погода**: Open-Meteo API (бесплатно, без ключей)
- **Лунный календарь**: алгоритм Jean Meeus (расчёт для любого года)
